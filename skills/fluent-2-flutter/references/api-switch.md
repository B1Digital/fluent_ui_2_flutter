```dart
  });
```

| Field | Type | Required | Default | Purpose |
| --- | --- | --- | --- | --- |
| `trackColor` | `WidgetStateProperty<Color?>?` | No | `null` | Track fill. Transparent while unchecked — as a token, never as `Colors.transparent`. |
| `trackBorderColor` | `WidgetStateProperty<Color?>?` | No | `null` | Track outline colour. Null and transparent are different: Fluent's `transparentStroke` becomes opaque `CanvasText` in high contrast, which is the only thing outlining a checked switch there. |
| `trackBorderWidth` | `WidgetStateProperty<double?>?` | No | `null` | Track outline width. Upstream declares `border: 1px solid` on the indicator in every state, checked included. |
| `trackBorderRadius` | `WidgetStateProperty<BorderRadius?>?` | No | `null` | Track corner radius. `borderRadiusCircular` upstream. |
| `thumbColor` | `WidgetStateProperty<Color?>?` | No | `null` | Thumb fill. Upstream paints it with the indicator's `color`, which is why it transitions on the same spec as the track. |
| `labelColor` | `WidgetStateProperty<Color?>?` | No | `null` | Label colour. Separate from [thumbColor] because upstream recolours the label only for disabled, and never on hover or press. |
| `textStyle` | `WidgetStateProperty<TextStyle?>?` | No | `null` | Label text style. Its colour is overridden by [labelColor]. |
| `trackSize` | `WidgetStateProperty<Size?>?` | No | `null` | Outer size of the track, border included — upstream sets `box-sizing: border-box`, so the 1px outline eats into these numbers rather than growing them. |
| `thumbSize` | `WidgetStateProperty<double?>?` | No | `null` | Painted diameter of the thumb. |
| `thumbTravel` | `WidgetStateProperty<double?>?` | No | `null` | How far the thumb travels when checked, in the reading direction. |
| `trackPadding` | `WidgetStateProperty<EdgeInsetsGeometry?>?` | No | `null` | Space around the track. Upstream's `margin` on the indicator. |
| `labelPadding` | `WidgetStateProperty<EdgeInsetsGeometry?>?` | No | `null` | Space around the label. Directional, because upstream shrinks the padding on whichever side faces the track. |
| `mouseCursor` | `WidgetStateProperty<MouseCursor?>?` | No | `null` | Cursor while hovering. |
