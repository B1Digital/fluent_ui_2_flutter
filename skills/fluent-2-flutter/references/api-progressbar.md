### `FluentProgressBarStyle`

#### Constructor: `FluentProgressBarStyle`

```dart
const FluentProgressBarStyle({

  });
```

| Field | Type | Required | Default | Purpose |
| --- | --- | --- | --- | --- |
| `railColor` | `WidgetStateProperty<Color?>?` | No | `null` | The unfilled groove behind the indicator. |
| `indicatorColor` | `WidgetStateProperty<Color?>?` | No | `null` | The filled portion. |
| `borderColor` | `WidgetStateProperty<Color?>?` | No | `null` | Outline colour. Null and transparent are different: Fluent's `transparentStroke` becomes opaque in high contrast, and this outline is the only thing that keeps the rail visible there. |
| `borderWidth` | `WidgetStateProperty<double?>?` | No | `null` | Outline width. Zero means no outline, which is not the same as a transparent one — a zero-width outline cannot become visible in high contrast. |
| `borderRadius` | `WidgetStateProperty<BorderRadius?>?` | No | `null` | Corner radius of both the rail and the indicator. |
| `thickness` | `WidgetStateProperty<double?>?` | No | `null` | The bar's height. Figma states this as a raw number per size — 2 and 4 — and binds no variable to it. |
