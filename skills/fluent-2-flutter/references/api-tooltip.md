## Behavior and parity notes

Hand-audited behavior that no constructor signature can express. Treat a
documented gap as a real gap: do not describe it as working, and do not
work around it by inventing an API.

- No Escape dismissal. `FluentTooltip` handles no keys at all: it opens on hover or keyboard-visible focus and closes only on blur or pointer exit. A keyboard user who focuses a trigger cannot dismiss the surface without moving focus, which WCAG 1.4.13 (Content on Hover or Focus) expects to be possible. If the tip can obscure content, provide the dismissal path at the trigger.
