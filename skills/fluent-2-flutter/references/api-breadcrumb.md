| `key` | `Key?` | No | `null` | Flutter widget identity. |
| `items` | `List<FluentBreadcrumbItem>` | Yes | — | The trail, root first. The last entry is the current page. |
| `size` | `FluentBreadcrumbSize` | No | `FluentBreadcrumbSize.medium` | Height and type ramp. |
| `maxDisplayedItems` | `int?` | No | `null` | How many crumbs may stay inline before the middle folds into the overflow popup. Null shows the whole trail. |
| `style` | `FluentBreadcrumbStyle?` | No | `null` | Overrides layered over the theme defaults. Merged last, so it wins. |
| `semanticLabel` | `String?` | No | `null` | Announced by assistive technology for the trail as a whole. |
