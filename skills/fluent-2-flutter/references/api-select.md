## Mapping and API rule

Status: **compose**. There is no one-to-one Fluent widget. Compose the mapped API deliberately and preserve the official semantics.

Mapped Flutter API: `FluentDropdown`.

The signatures below are extracted from the checked-out Dart source. React
properties from the Microsoft site are design evidence, not Flutter fields.

## Behavior and parity notes

Hand-audited behavior that no constructor signature can express. Treat a
documented gap as a real gap: do not describe it as working, and do not
work around it by inventing an API.

- Not native `<select>` parity. `FluentDropdown<T>` renders a Flutter overlay, so there is no OS-native picker on mobile, no platform typeahead, and no browser-level form integration. Choose it for a Fluent-styled listbox, not because a native select is required.
