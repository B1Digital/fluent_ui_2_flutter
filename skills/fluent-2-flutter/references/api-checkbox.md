Source: `packages/fluent_2_web/lib/src/inputs/checkbox.dart`

#### State, callback, and accessibility fields

- `checked` (`bool?`): The tri-state value. Null is the mixed state.
- `onChanged` (`ValueChanged<bool?>?`): Invoked with the next value on tap and on Space or Enter. Null disables the checkbox.
- `focusNode` (`FocusNode?`): Focus node to use. One is created internally when omitted.
- `autofocus` (`bool`): Whether to take focus on mount.
- `semanticLabel` (`String?`): Announced by assistive technology alongside the checked state.

| Field | Type | Required | Default | Purpose |

| `indicatorBackgroundColor` | `WidgetStateProperty<Color?>?` | No | `null` | The indicator box fill. Fluent's `transparentBackground` in every state except checked — never `Colors.transparent`, which stays transparent in high contrast where the token turns opaque. |
| `indicatorBorderColor` | `WidgetStateProperty<Color?>?` | No | `null` | The indicator box border colour. |
| `foregroundColor` | `WidgetStateProperty<Color?>?` | No | `null` | Label colour. Upstream sets this on the root and lets the label inherit. |
| `borderWidth` | `WidgetStateProperty<double?>?` | No | `null` | Indicator border width. Zero means no border, which is not the same as a transparent one — a zero-width border cannot become visible in high contrast. |
| `borderRadius` | `WidgetStateProperty<BorderRadius?>?` | No | `null` | Indicator corner radius. |
| `textStyle` | `WidgetStateProperty<TextStyle?>?` | No | `null` | Label text style. Its colour is overridden by [foregroundColor]. |
| `indicatorMargin` | `WidgetStateProperty<EdgeInsetsGeometry?>?` | No | `null` | Inset around the indicator box. This is the click target upstream builds by oversizing the hidden `<input>`, so it is padding rather than margin here: it is inside the hit area. |
| `labelPadding` | `WidgetStateProperty<EdgeInsetsGeometry?>?` | No | `null` | Inset around the label, tight on the side facing the indicator. |
| `indicatorSize` | `WidgetStateProperty<double?>?` | No | `null` | Indicator box edge length, border included. |
| `glyphSize` | `WidgetStateProperty<double?>?` | No | `null` | Glyph box edge length. Upstream expresses this as the indicator's `fontSize`, since the glyph is an icon font-sized inside the box. |
| `minimumSize` | `WidgetStateProperty<Size?>?` | No | `null` | Minimum size of the whole control. |
| `mouseCursor` | `WidgetStateProperty<MouseCursor?>?` | No | `null` | Cursor while hovering. |
