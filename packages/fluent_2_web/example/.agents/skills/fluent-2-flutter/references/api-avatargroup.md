A Fluent 2 avatar group: several people shown as one unit.

Source: `packages/fluent_2_web/lib/src/surfaces/avatar_group.dart`

#### Constructor: `FluentAvatarGroup`

```dart
const FluentAvatarGroup({
```

#### Constructor: `FluentAvatarGroupStyle`

```dart
const FluentAvatarGroupStyle({
    this.spacing,

    this.outlineWidth,
    this.dividerColor,
    this.dividerWidth,
    this.borderRadius,
    this.diameter,
  });
```

| Field | Type | Required | Default | Purpose |
| --- | --- | --- | --- | --- |
| `spacing` | `WidgetStateProperty<double?>?` | No | `null` | Gap between neighbouring avatars. **Negative** for `FluentAvatarGroupLayout.stack`, which is how the overlap is expressed. |
| `outlineColor` | `WidgetStateProperty<Color?>?` | No | `null` | The ring each avatar takes in a stacked group, so an overlapped avatar still reads as a separate person. |
| `outlineWidth` | `WidgetStateProperty<double?>?` | No | `null` | Width of [outlineColor]. Zero in the spread and pie layouts. |
| `dividerColor` | `WidgetStateProperty<Color?>?` | No | `null` | The rule between two pie slices. |
| `dividerWidth` | `WidgetStateProperty<double?>?` | No | `null` | Width of [dividerColor]. |
| `borderRadius` | `WidgetStateProperty<BorderRadius?>?` | No | `null` | The pie's own clip, and the outline radius in a stacked group. |
| `diameter` | `WidgetStateProperty<double?>?` | No | `null` | One avatar's edge length. The pie is exactly this big; a spread or stacked group is this tall. |
