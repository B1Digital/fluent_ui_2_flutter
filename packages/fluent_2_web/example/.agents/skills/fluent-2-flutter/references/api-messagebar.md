### `FluentMessageBar`

A Fluent 2 message bar: a tinted strip reporting a condition, with optional actions and a dismiss affordance.

Source: `packages/fluent_2_web/lib/src/surfaces/message_bar.dart`

#### Constructor: `FluentMessageBar`

```dart
const FluentMessageBar({
    super.key,
    required this.child,
    this.intent = FluentMessageBarIntent.info,
    this.layout = FluentMessageBarLayout.singleLine,
    this.shape = FluentMessageBarShape.rounded,
    this.title,
    this.icon,
    this.showIcon = true,
    this.actions = const <Widget>[],
    this.onDismiss,
    this.dismissSemanticLabel = 'Dismiss',
    this.style,
    this.liveRegion = true,
    this.semanticLabel,
  });
```

| Field | Type | Required | Default | Purpose |
| --- | --- | --- | --- | --- |
| `key` | `Key?` | No | `null` | Flutter widget identity. |
| `child` | `Widget` | Yes | — | The message. |
| `intent` | `FluentMessageBarIntent` | No | `FluentMessageBarIntent.info` | What the message is about. Moves the surface, border and glyph together. |
| `layout` | `FluentMessageBarLayout` | No | `FluentMessageBarLayout.singleLine` | How the bar arranges its glyph, body and actions. |
| `shape` | `FluentMessageBarShape` | No | `FluentMessageBarShape.rounded` | Corner treatment. |
| `title` | `Widget?` | No | `null` | A lead-in flowed inline before [child], in the strong ramp. |
| `icon` | `Widget?` | No | `null` | Overrides the glyph [intent] would otherwise select. |
| `showIcon` | `bool` | No | `true` | Whether a glyph is drawn at all. False removes it and its gap. |
| `actions` | `List<Widget>` | No | `const <Widget>[]` | Action affordances. Usually small `FluentButton`s. |
| `onDismiss` | `VoidCallback?` | No | `null` | Invoked by the dismiss button. Null renders no dismiss button. |
| `dismissSemanticLabel` | `String` | No | `'Dismiss'` | Announced by assistive technology for the dismiss button, which has no text of its own. |
| `style` | `FluentMessageBarStyle?` | No | `null` | Overrides layered over the theme defaults. Merged last, so it wins. |
| `liveRegion` | `bool` | No | `true` | Whether assistive technology announces the bar when it appears. |
| `semanticLabel` | `String?` | No | `null` | Announced by assistive technology in place of the subtree's own reading of the title and body. |

#### State, callback, and accessibility fields

- `onDismiss` (`VoidCallback?`): Invoked by the dismiss button. Null renders no dismiss button.
- `semanticLabel` (`String?`): Announced by assistive technology in place of the subtree's own reading of the title and body.

| Field | Type | Required | Default | Purpose |
| --- | --- | --- | --- | --- |
| `backgroundColor` | `WidgetStateProperty<Color?>?` | No | `null` | Surface fill. The intent axis moves this and [borderColor] together. |
| `foregroundColor` | `WidgetStateProperty<Color?>?` | No | `null` | Title and body colour. `Neutral/Foreground/1/Rest` on every intent — Fluent tints the glyph, never the prose. |
| `borderColor` | `WidgetStateProperty<Color?>?` | No | `null` | Border colour. Null and transparent are different: Fluent's transparent tokens become opaque in high contrast. |
| `borderWidth` | `WidgetStateProperty<double?>?` | No | `null` | Border width. Zero means no border, which is not the same as a transparent one — a zero-width border cannot become visible in high contrast. |
| `borderRadius` | `WidgetStateProperty<BorderRadius?>?` | No | `null` | Corner radius. |
| `iconColor` | `WidgetStateProperty<Color?>?` | No | `null` | Status glyph tint. The only property the intent axis tints. |
| `iconSize` | `WidgetStateProperty<double?>?` | No | `null` | Status glyph edge length. |
| `titleTextStyle` | `WidgetStateProperty<TextStyle?>?` | No | `null` | Title type ramp. Its colour is overridden by [foregroundColor]. |
| `textStyle` | `WidgetStateProperty<TextStyle?>?` | No | `null` | Body type ramp. Its colour is overridden by [foregroundColor]. |
| `padding` | `WidgetStateProperty<EdgeInsetsGeometry?>?` | No | `null` | Padding inside the border. |
| `gap` | `WidgetStateProperty<double?>?` | No | `null` | Horizontal spacing between the glyph, the body, each action and the dismiss button. |
| `multilineGap` | `WidgetStateProperty<double?>?` | No | `null` | Vertical spacing between the content row and the actions row. Multi-line only; a single-line bar puts its actions in the content row at [gap]. |
| `iconPadding` | `WidgetStateProperty<EdgeInsetsGeometry?>?` | No | `null` | Inset above the glyph. Zero on a single-line bar, whose row centres instead. |
| `bodyPadding` | `WidgetStateProperty<EdgeInsetsGeometry?>?` | No | `null` | Inset above the body. Zero on a single-line bar, whose row centres instead. |
| `minimumSize` | `WidgetStateProperty<Size?>?` | No | `null` | Minimum size of the bar. |
| `dismissButtonStyle` | `FluentButtonStyle?` | No | `null` | Style handed to the dismiss button. |
