Paints the activity ring — and, with [gap] left at zero, the flat outline an avatar takes inside a stacked `FluentAvatarGroup`.

```dart
    this.width = 0,
    this.gap = 0,
    this.opacity = 1,
  });
```

| Field | Type | Required | Default | Purpose |
| --- | --- | --- | --- | --- |
| `borderRadius` | `BorderRadius` | Yes | — | The avatar's own corner radius. The ring is concentric to it. |
| `color` | `Color?` | No | `null` | Ring stroke colour. Figma's `Avatar color` → `Active stroke`. |
| `gapColor` | `Color?` | No | `null` | Fills the gap between the avatar and the ring. Null leaves it clear, which is what a stack outline wants. |
| `width` | `double` | No | `0` | Ring stroke width. Zero paints nothing at all. |
| `gap` | `double` | No | `0` | Clear space between the avatar's edge and the ring's inner edge. |
| `opacity` | `double` | No | `1` | Transition opacity, 0 to 1. Multiplies [color] and [gapColor]; it is a tween value, not a token, and is 1 whenever nothing is animating. |

| Field | Type | Required | Default | Purpose |
| --- | --- | --- | --- | --- |
| `backgroundColor` | `WidgetStateProperty<Color?>?` | No | `null` | The disc behind the initials or icon. Figma's `Avatar color` → `Background`; unused when an image fills the avatar. |
| `foregroundColor` | `WidgetStateProperty<Color?>?` | No | `null` | Initials and icon colour. Figma's `Avatar color` → `Foreground`. |
| `borderColor` | `WidgetStateProperty<Color?>?` | No | `null` | The hairline drawn *inside* the avatar's own box. Figma's `Avatar color` → `Inside stroke`, which is a transparent token for every mode except `Overflow (Avatar group)` — and transparent tokens turn opaque in high contrast, which is the point of keeping it rather than dropping it. |
| `borderWidth` | `WidgetStateProperty<double?>?` | No | `null` | Width of [borderColor]. Ramps 1, 2, 3, 4 with the avatar's size. |
| `borderRadius` | `WidgetStateProperty<BorderRadius?>?` | No | `null` | Corner radius. Circular, or `FluentRadius.small` for the square shape. |
| `ringColor` | `WidgetStateProperty<Color?>?` | No | `null` | The activity ring's stroke. Figma's `Avatar color` → `Active stroke`. |
| `ringGapColor` | `WidgetStateProperty<Color?>?` | No | `null` | Fills the gap between the avatar and the activity ring, so the ring reads against a coloured backdrop. Figma's `Neutral/Background/1/Rest`. |
| `ringWidth` | `WidgetStateProperty<double?>?` | No | `null` | Activity ring stroke width. Also the width of the gap inside it — Figma and React agree that the ring sits one ring-width clear of the avatar. |
| `textStyle` | `WidgetStateProperty<TextStyle?>?` | No | `null` | Initials type ramp. |
| `iconSize` | `WidgetStateProperty<double?>?` | No | `null` | Icon edge length, when the avatar shows an icon rather than initials. |
| `diameter` | `WidgetStateProperty<double?>?` | No | `null` | The avatar's own edge length. Square in every size. |
