Source: `packages/fluent_2/lib/src/overlays/popover.dart`

```dart

    this.size = FluentPopoverSize.medium,
```

- `open` (`bool`): Whether the surface is showing.
- `onOpenChanged` (`ValueChanged<bool>?`): Reports every open and close this widget performs — Escape, an outside tap. Null disables the popover.
- `semanticLabel` (`String?`): Announced by assistive technology when the surface appears.
