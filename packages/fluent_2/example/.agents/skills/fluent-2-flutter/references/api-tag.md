## Behavior and parity notes

Hand-audited behavior that no constructor signature can express. Treat a
documented gap as a real gap: do not describe it as working, and do not
work around it by inventing an API.

- No keyboard dismissal on the tag itself. `FluentTag` handles no keys; its `dismiss` field is a caller-supplied `Widget?` that must already carry its own interaction surface. The dismiss affordance is only reachable if the caller made it independently focusable, and Delete or Backspace on a focused tag does nothing. Supply a focusable dismiss control rather than assuming the tag provides the path.
