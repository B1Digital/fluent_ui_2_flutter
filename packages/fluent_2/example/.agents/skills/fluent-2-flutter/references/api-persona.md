### `FluentPersona`

A Fluent 2 persona: a [FluentAvatar] — or a [FluentPresenceBadge] — beside up to four lines of text.

Source: `packages/fluent_2/lib/src/surfaces/persona.dart`


### `FluentPersonaStyle`

Source: `packages/fluent_2/lib/src/surfaces/persona_style.dart`

#### Constructor: `FluentPersonaStyle`

```dart
const FluentPersonaStyle({
    this.primaryTextStyle,
    this.secondaryTextStyle,
    this.primaryColor,
    this.secondaryColor,
    this.gap,
    this.contentPadding,
    this.lineOverlap,
  });
```

| Field | Type | Required | Default | Purpose |
| --- | --- | --- | --- | --- |
| `primaryTextStyle` | `WidgetStateProperty<TextStyle?>?` | No | `null` | Type ramp of the first line. `body1`, or `subtitle2` from the two largest sizes up. |
| `secondaryTextStyle` | `WidgetStateProperty<TextStyle?>?` | No | `null` | Type ramp shared by the second, third and fourth lines — upstream styles all three through one `optionalText` class, and Figma ramps all three together. |
| `primaryColor` | `WidgetStateProperty<Color?>?` | No | `null` | First-line colour. Figma's `Neutral/Foreground/1/Rest`. |
| `secondaryColor` | `WidgetStateProperty<Color?>?` | No | `null` | Colour of the second, third and fourth lines. Figma's `Neutral/Foreground/2/Rest`. |
| `gap` | `WidgetStateProperty<double?>?` | No | `null` | Space between the avatar (or presence badge) and the text block. Figma's `Avatar spacing` / `Presence badge spacing`. |
| `contentPadding` | `WidgetStateProperty<EdgeInsets?>?` | No | `null` | Inset above and below the whole text block. Figma's `Content` frame binds `Spacing/Vertical/XXS` top and bottom — but only when there is a second line to inset from; the single-line variant carries no wrapper at all. |
| `lineOverlap` | `WidgetStateProperty<double?>?` | No | `null` | How far the second line is pulled *up* into the first. Figma's `Content` frame states `itemSpacing: -2` and upstream writes the same number as `secondLineSpacing { marginTop: -2px }`. |
